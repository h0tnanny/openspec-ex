# Спецификация: Базовое ядро TypeScript и модульная декомпозиция

## Требование 1: Строгая типизация доменных моделей (Strict Domain Types)
Система ДОЛЖНА объявлять и экспортировать строгие TypeScript-интерфейсы и типы для всех основных сущностей:
- `AgentDefinition` и `AgentId`: идентификаторы и метаданные путей для всех 23+ поддерживаемых AI-инструментов.
- `BackupManifest` и `SnapshotFileEntry`: схемы снимков с контрольными суммами SHA-256 и временными метками.
- `PresetSchema` и `PresetBundle`: форматы локальных, глобальных и встроенных фабричных пресетов.
- `SpecViewerData` и `DiscoveryBrief`: структуры данных для генерации интерактивного отчета `spec-viewer.html`.
- `CliCommand` и `CliContext`: типы контекста и аргументов CLI.

## Требование 2: Декомпозиция генератора на изолированные модули
Монолитная логика генератора ДОЛЖНА быть разделена на независимые модули без циклических зависимостей:
1. `src/core/skills/`: отдельные типизированные генераторы для скиллов (`explore`, `propose`, `apply`, `archive`, `sync`, `edit`).
2. `src/core/rules/`: генераторы правил для различных сред (`Antigravity`, `Cursor`, `Claude`, `Windsurf`, `Copilot`, `Cline`, `Universal`).
3. `src/core/viewer/`: компилятор HTML-страницы со встроенным визуализатором Mermaid.js.
4. `src/core/backup/`: менеджер бекапов и верификатор целостности SHA-256.
5. `src/core/presets/`: менеджер локальных/глобальных пресетов и валидатор пакетов.
6. `src/core/installer/`: оркестратор создания структуры каталогов и инициализации агентов.

# Спецификация: Сборка, упаковка и рантайм

## Требование 1: Двухформатная компиляция (Dual CJS/ESM)
Процесс сборки `npm run build` с использованием `tsup` ДОЛЖЕН генерировать:
- `dist/index.cjs` для окружений CommonJS.
- `dist/index.mjs` для окружений ES Modules.
- `dist/index.d.ts` с полной декларацией типов.
- `dist/bin/cli.cjs` с обязательным заголовком `#!/usr/bin/env node` и поддержкой прямого исполнения через `npx openspec-ex`.

## Требование 2: Гарантия нулевых внешних зависимостей (Zero Runtime Dependencies)
- В `package.json` поле `"dependencies"` ДОЛЖНО оставаться пустым объектом `{}`.
- Исходный код и скомпилированные бандлы ДОЛЖНЫ использовать исключительно стандартные модули платформы Node.js (`fs`, `path`, `crypto`, `os`, `child_process`, `http`).

# Спецификация: Тестирование и контроль регрессий

## Требование 1: Golden Master Snapshot-тестирование
Тестовый набор на базе `vitest` ДОЛЖЕН содержать автоматические тесты-снимки (snapshots), проверяющие, что сгенерированные файлы скиллов, шаблонов и правил для всех 23+ AI-агентов идентичны эталонным образцам и не содержат повреждений синтаксиса или пропущенных переменных.

## Требование 2: Интеграционное тестирование CLI
Тесты ДОЛЖНЫ проверять выполнение всех команд CLI (`init`, `backup`, `restore`, `preset`, `view`) во временных изолированных каталогах.
